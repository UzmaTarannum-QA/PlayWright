Each concept was introduced to solve a problem in the previous one.

1. Callback

Why was it introduced?

Some operations take time. JavaScript needed a way to execute code after those operations complete.

Definition

A function passed into another function that runs later.

Example

function greet(callback) {
   console.log("Hello");
   callback();
}

greet(() => console.log("Uzma"));

Problem Created

login(() => {
   navigate(() => {
      search(() => {
         logout(() => {
            console.log("Done");
         });
      });
   });
});

Callback Hell.

Playwright Relevance

Rarely used directly. Playwright is Promise-based.

Interview Answer:
Callbacks were the original async solution. Promises were introduced to solve Callback Hell.

2. Promise

Definition

Represents a future result of an asynchronous operation.

States

Pending
↓
Fulfilled
OR
Rejected

Example

const p = new Promise((resolve,reject)=>{

   const success = true;

   if(success){
      resolve("Success");
   }else{
      reject("Failed");
   }

});

Consume

p.then(result => console.log(result))
 .catch(error => console.log(error));

Playwright Example

const result =
page.goto("https://google.com");

page.goto() returns a Promise.

Almost every Playwright API returns a Promise.
Interview Answer:
Playwright is Promise-based because browser actions take time.

3. async

Definition

Makes a function automatically return a Promise. 

async function greet() {
   return "Hello";
}
Actually: 
Promise.resolve("Hello")

Playwright Example

async function login(page){

   await page.fill("#user","admin");

   await page.fill("#pass","admin123");

   await page.click("#login");

}
Any function using await must be async.
Interview Answer:
async marks a function as asynchronous and ensures it returns a Promise.

4. await

Definition

Waits for a Promise to complete.

Wrong

page.click("#login");

page.fill("#search","iphone");

Correct

await page.click("#login");

await page.fill("#search","iphone");

Playwright Example

await page.goto(url);

await page.fill("#username","admin");

await page.click("#login");
Forgetting await is one of the most common Playwright mistakes.
Interview Answer:
await pauses the current async function until a Promise settles. It does not block JavaScript entirely.

5. try / catch

Why?

Promises can fail. We need a clean way to handle errors.

Example

try {

   await page.goto(url);

   await page.click("#login");

}
catch(error){

   console.log(error.message);

}

Playwright Example

try {

   await page.waitForResponse("**/orders");

}
catch(error){

   await page.screenshot({
      path:"failure.png"
   });

   throw error;
}
try/catch is the async version of .catch()
Interview Answer:
Used with async/await for handling rejected Promises.

6. waitForEvent()

Why?

Many user actions trigger browser events.

  • Popup
  • Download
  • Dialog
  • New Tab
  • File Chooser

Wrong

await page.click("#download");

await page.waitForEvent("download");

Correct

const [download] =
await Promise.all([

   page.waitForEvent(
      "download"
   ),

   page.click("#download")

]);
Arm the listener first, then fire the trigger.
Interview Answer:
waitForEvent waits for browser events. Usually combined with Promise.all so no event is missed.

7. waitForResponse()

Why?

Used when UI behavior depends on an API call.

Example

await Promise.all([

   page.waitForResponse(
      "**/orders"
   ),

   page.click("#search")

]);

Advanced

const response =
await page.waitForResponse(
   response =>
      response.url()
         .includes("/orders")
      &&
      response.status() === 200
);
Interview Answer:
Used to synchronize tests with API responses.

8. waitForURL()

Why?

Used when actions result in navigation.

Example

await Promise.all([

   page.waitForURL(
      "**/dashboard"
   ),

   page.click("#login")

]);
Most common Promise.all interview question.
Interview Answer:
Ensures navigation completes before continuing.

9. Promise.all()

Definition

Runs multiple Promises in parallel and waits for all.

Without Promise.all

await task1();
await task2();
await task3();

With Promise.all

await Promise.all([
   task1(),
   task2(),
   task3()
]);

Playwright Example

await Promise.all([

   page.waitForURL(
      "**/dashboard"
   ),

   page.click("#login")

]);
Interview Answer:
Runs tasks in parallel. Fails if any one Promise fails.

10. Promise.allSettled()

Problem

Promise.all fails fast. Sometimes we need every result.

Example

const results =
await Promise.allSettled([

   api1(),

   api2(),

   api3()

]);

Output

[
  {status:"fulfilled"},
  {status:"rejected"},
  {status:"fulfilled"}
]

Playwright Example

const validations =
await Promise.allSettled([

   page.locator("#user")
       .textContent(),

   page.locator("#role")
       .textContent(),

   page.locator("#team")
       .textContent()

]);
Interview Answer:
Promise.all waits for all but fails on first error. Promise.allSettled waits for all regardless of success or failure.
