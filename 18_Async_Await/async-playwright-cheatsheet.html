Playwright Async JavaScript Cheat Sheet

1. Callback

Definition: A function passed as an argument to another function.

Usage:

doSomething(callback)

Pros: Simple for small tasks.

Cons: Leads to Callback Hell.

Playwright: Rarely used directly. Promises are preferred.

2. Promise

Definition: Represents a value that will be available in the future.

States: Pending → Resolved → Rejected

Usage:

promise.then().catch()

Pros: Cleaner than callbacks.

Cons: Long chains can become difficult to read.

Playwright: Almost every Playwright API returns a Promise.

page.goto(url)

3. async

Definition: Makes a function automatically return a Promise.

Usage:

async function login() {

}

Pros: Cleaner asynchronous code.

Cons: Must be paired with await for full benefit.

Playwright:

async function login(page) {

}

4. await

Definition: Waits for a Promise to complete.

Usage:

await promise

Pros: Makes async code look synchronous.

Cons: Sequential waits may slow execution.

Playwright:

await page.click("#login");
await page.fill("#user","admin");

5. Promise.all()

Definition: Runs multiple Promises in parallel and waits for all.

Usage:

await Promise.all([p1,p2,p3]);

Pros: Faster execution.

Cons: Fails if any one Promise fails.

Playwright:

await Promise.all([
 page.waitForNavigation(),
 page.click("#login")
]);

Interview Keyword: Parallel Execution

6. Promise.race()

Definition: Returns the result of the first completed Promise.

Usage:

await Promise.race([p1,p2]);

Pros: Useful for timeout handling.

Cons: Other Promises continue running.

Playwright Use Case:

await Promise.race([
 apiCall,
 timeoutPromise
]);

Interview Keyword: First Winner Wins

Revision Flow

Callback
   ↓
Promise
   ↓
async
   ↓
await
   ↓
Promise.all
   ↓
Promise.race

Remember:
Promise = Future Result
async = Returns Promise
await = Wait for Promise
Promise.all = Wait for All
Promise.race = Wait for First
